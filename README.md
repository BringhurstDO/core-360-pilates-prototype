# Core 360 Pilates Education Prototype

Lean MVP prototype for an anatomy-forward Pilates education platform. The current build focuses on an instructor-centered exercise library, exercise detail pages, simplified anatomy overlays, and an instructor/client content split.

## Prototype Scope

- Static exercise library with local TypeScript content files
- Instructor and client view toggle on exercise detail pages
- Simplified anatomy overlay driven by exercise muscle group data
- Feedback guide for early review

## Local Development

```bash
npm install
npm run dev
```

The dev server defaults to `http://localhost:3004`.

## Build

```bash
npm run build
```

## Notes

Content, images, and anatomy regions are prototype placeholders. The anatomy SVG is simplified for education review and is not medical-grade.
